# Performance metrics

Start `AgBot - Performance - <TODAY>`. Apply the shared coaching policy.
Present available VO2max, endurance/hill scores, running lactate threshold
(HR/pace/power and dates), cycling FTP, race estimates and relevant changes.
Explain what each meaningful number suggests and what it does not establish.
Surface stale, unsupported, missing or failed metrics honestly; never turn them
into zero or invent an estimate. Connect trends to actual training and goals, not
to a demand to chase Garmin labels or increase intensity regardless of recovery.
Fuel-use estimates are activity-level estimates, not body-composition measurements.
